How the AI Works

From raw retinal image to clinical-grade severity classification in 4 steps

01
📷

Image Acquisition

A retinal fundus image is captured using a fundus camera. The image is preprocessed using CLAHE (Contrast Limited Adaptive Histogram Equalization) for enhanced vessel visibility.

OpenCV • Pillow • CLAHE
→
02
🔬

Feature Extraction

The preprocessed image is fed into a pretrained EfficientNet-B3 CNN. Transfer learning extracts deep features such as microaneurysms, hemorrhages, and neovascularization patterns.

EfficientNet-B3 • PyTorch • Transfer Learning
→
03
🎯

Severity Classification

The model classifies the image into one of 5 severity grades: No DR, Mild, Moderate, Severe, or Proliferative DR. Quadratic Weighted Kappa ensures robust multi-class scoring.

Softmax • 5-Class • QWK Metric
→
04
🗺️

Explainability (Grad-CAM)

Gradient-weighted Class Activation Mapping highlights the exact regions of the retina that influenced the AI decision — providing clinical transparency and trust for ophthalmologists.

Grad-CAM • XAI • Heatmap Overlay

About the Project

AI-Based Retinopathy Screening

Diabetic Retinopathy (DR) is the leading cause of blindness in the working-age population worldwide. Early detection through systematic screening can prevent up to 90% of vision loss cases — but access to qualified ophthalmologists remains limited in rural and underserved regions.

This project leverages state-of-the-art deep learning to build an automated, scalable, and clinically trustworthy DR screening solution. By combining EfficientNet-B3's superior accuracy with Grad-CAM explainability, we ensure that AI decisions are interpretable by medical professionals.
